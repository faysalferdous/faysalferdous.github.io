## Publish

Extract the ZIP and upload the files and folders inside it to the root of:

```text
https://github.com/faysalferdous/faysalferdous.github.io
```

Expected structure:

```text
faysalferdous.github.io/
├── index.html
├── styles.css
├── script.js
├── robots.txt
├── sitemap.xml
├── .nojekyll
└── assets/
```

Configure GitHub Pages:

```text
Settings → Pages → Deploy from a branch → main → / (root)
```

Published URL:

```text
https://faysalferdous.github.io/
```
